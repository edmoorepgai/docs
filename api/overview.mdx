The PG:AI API gives you programmatic access to account intelligence, territory data, contacts, content, and AI-powered insights. Use it to pull intelligence into your own tools, automate workflows, or build custom integrations.

## Base URL

```
https://api.getpg.ai/public-api/v1
```

## Quick Start

<Steps>
  <Step title="Get your API key">
    Generate an API key in **Settings → API Keys** within your PG:AI workspace.
  </Step>
  <Step title="Make your first request">
    ```bash
    curl -X POST "https://api.getpg.ai/public-api/v1/accounts" \
      -H "x-api-key: your_api_key" \
      -H "Content-Type: application/json" \
      -d '{}'
    ```
  </Step>
  <Step title="Follow a common flow">
    See [Common Flows](/api/common-flows) for end-to-end examples — add a company, enrich contacts, list canvas, and more.
  </Step>
  <Step title="Explore endpoints">
    Scroll the **API** sidebar — **Getting started** is at the top, then Accounts, Companies, Contacts, and the rest.
  </Step>
</Steps>

## Async operations

Some endpoints return `202 Accepted` with a `public_operation_id`. Poll `GET /operations/{public_operation_id}` until the job completes. See [Common Flows](/api/common-flows#add-a-company-and-wait-for-enrichment) for a full example.

## Rate limits

API requests are rate-limited based on your plan. When you hit the limit, the API returns `429 Too Many Requests`. See [Authentication](/api/authentication) for rate limit headers.
